商家条码与面单助手：隐私政策

本政策由开发者 luo 制定，自 2026 年 10 月 6 日起生效。

本政策的联系渠道为 GitHub 仓库 Issues。请勿在公开 Issue 中提交姓名、地址、订单、签名下载链接、账号密码、验证码或其他敏感信息。

本扩展是独立开发的商家 PDF 处理工具，不是 SHEIN 官方产品。政策地址为：https://sitholethemba289-jpg.github.io/shein-barcode-helper-privacy/privacy.html

1. 本扩展的用途

本扩展是独立开发的商家 PDF 处理工具，用于商品条码标签合成、发货面单拆分以及按规格和数量整理下载。它不是 SHEIN 官方产品。

2. 处理哪些信息

根据你使用的功能，本扩展可能在浏览器中读取、处理或保存：

- 你手动导入、上传保存或通过平台取得的 PDF，包括条码、模板和发货面单。

- 支持的商家页面中已勾选的订单/发货单标识、商品规格、数量、面单数，以及相关平台接口返回的信息。

- 模板名称、模板文件、布局位置和大小、默认模板等本地设置。

- 平台提供的 PDF 下载地址及完成请求所需的平台上下文，例如当前页面和店铺标识。下载地址可能含平台生成的临时访问参数。

- PDF 原有内容可能包含企业、商品或收货人的信息；本扩展处理这些文件时也会处理其中的内容。请只导入你有权处理的文件。

同源平台接口请求会使用浏览器已有的登录会话。当前代码未实现主动读取密码、导出登录 Cookie、收集所有网站浏览记录或记录键盘输入的功能。

3. 如何使用与传输

PDF 合成、版式检查、预览和拆分在本机浏览器中完成，用于你发起的整理、下载或打印操作。

自动处理会向你正在使用的商家平台请求所需数据，或下载该平台提供的 PDF。跨源 PDF 下载在当前代码中不主动携带登录 Cookie。平台会按照其自身规则处理收到的访问请求。

当前版本未配置开发者服务器、广告、统计分析服务或将上述 PDF/业务数据上传到开发者服务器的功能。本扩展不出售这些业务数据，不将其用于广告画像。浏览器或商店自身的诊断行为由各自政策约束。

如你主动通过 GitHub 仓库 Issues 寻求支持，你提交的内容会按照 GitHub 的服务规则处理，并可能对其他访问者公开。请先遮盖姓名、地址、订单、签名下载链接和令牌等敏感内容；不要发送账号密码或验证码。

4. 保存位置和期限

- 自定义模板文件保存在扩展的本地 IndexedDB；模板列表、布局和偏好保存在浏览器扩展本地存储中。当前代码未使用 chrome.storage.sync 上传这些设置。

- 自动接收的临时 PDF 可能保存在本地 IndexedDB。超过 24 小时的临时捕获文件，会在下一次执行相关清理流程时删除；不是到时立即自动删除。如果之后不再使用相关功能，文件可能继续保留。

- 工作台手动导入的本次条码文件通常只在页面内存中保留；上传并“保存”的自定义模板会持久保存，这两者不同。

- 下载到系统下载文件夹的 PDF 属于用户文件，不会因关闭工作台、清理缓存或卸载扩展而自动删除。

- 自定义模板和设置会保留到你删除对应内容、清除扩展数据或卸载扩展。卸载前请先保留自己的原模板文件和必要设置。

5. 权限与选择

storage 用于本地模板信息和布局设置；downloads 用于保存你确认的输出文件。自动页面功能限定于支持的商家站点。

因为平台 PDF 可能位于不同 HTTPS 站点，当前 Manifest 声明可选 HTTPS 主机权限；实际使用时按本次 PDF 所在站点申请，而不是在安装时请求所有 HTTPS 网站的访问权。已授予的站点权限可能持续有效，直到你撤销或卸载。

你可以拒绝可选权限；对应自动下载可能不可用，其他功能仍应在其所需权限范围内使用。你可以通过浏览器的扩展管理撤销站点授权、停用或卸载扩展。

6. 删除与安全

你可以在工作台删除自定义模板、清空当前手动导入文件，或通过浏览器管理清除扩展数据。当前版本没有统一的一键导出/迁移或一键删除全部缓存入口；需要进一步删除帮助时可联系开发者。

请在可信设备上操作，不要共享未经遮盖的业务 PDF。使用原平台登录会话的行为不代表扩展获得你的账号密码。任何软件都无法承诺绝对安全。

7. 更新与联系

当处理方式发生实质变化时，开发者应同步更新此政策与商店披露。如果需要查阅、更正或删除你主动提交的支持资料，请通过上方 GitHub Issues 联系开发者，并不要在公开内容中提供敏感信息。

这份政策不是法律意见；如扩展的处理方式、支持渠道或数据流发生变化，应在发布前重新核对并更新。
